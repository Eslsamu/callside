# Callside

A local desktop and browser call assistant for people in interviews, sales conversations, and meetings. The operator keeps attention on the conversation while following live transcripts and short suggested replies. OpenAI is the initial provider; adapters allow future providers. Audio must begin with an explicit user action, and the app must make capture, model activity, cost-bearing mode, and errors visible. No session database or telemetry. Keys stay in the local server. Desktop capture plus a global keyboard trigger is the primary experience; browser capture and a deterministic no-key demo are supported. Interface language: German. Repository documentation: English.
